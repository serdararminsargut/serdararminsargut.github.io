# Claude Repository Instructions

This repository uses `AGENTS.md` as the primary shared operating policy for AI-assisted work.

Before making any change:

1. Read and follow the root `AGENTS.md` in full.
2. Inspect the current repository state and recent commits.
3. Verify the reported problem before editing production-critical files.
4. Prefer the smallest safe and reversible change.
5. Do not modify `robots.txt`, `sitemap.xml`, canonical URLs, analytics, structured data, redirects, or deployment-related configuration without a verified reason.
6. Do not assume another AI agent's conversational context is available; use repository files and Git history as the shared source of truth.
7. After a production-relevant change, verify deployment and live behavior before reporting success.

If this file conflicts with `AGENTS.md`, follow `AGENTS.md`, except where the user's latest explicit instruction requires otherwise.
